# Cyber security

Cyber security from 21 feeds, Blackhat Library: Hacking techniques and research, CyberWire Daily, Darknet Diaries: videos from their newest posts.

```sh
edits rss cyber-security --list                    # the newest posts (--json for programs)
edits rss cyber-security -n 3                       # a video for each of the 3 newest
edits rss cyber-security --feed all -n 5 --preset sinema-bant
edits follow cyber-security --post tiktok --every 30 # RSS in, video made, posted out (edits watch runs it)
```
