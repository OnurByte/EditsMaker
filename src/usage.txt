edits - give it a link, a topic or a file; get finished edits.

USAGE
  edits <youtube-link | topic | video-file> [options]
  edits doctor                 check ffmpeg, yt-dlp, whisper and the LLM command
  edits encoder [auto|nvenc|videotoolbox|cpu]  what renders the video (GPU or CPU), saved for every run
  edits setup                  fetch ffmpeg and yt-dlp if missing (also done on first use)
  edits info                   version, updates, the author's GitHub and X
  edits update [check|on|off]  install the newest release now; on by default once a day (EDITS_AUTO_UPDATE=0 stops it)
  edits rate <clip.mp4> +|-    teach your taste: liked / disliked
  edits preset list | show NAME           presets are JSON: read one in full
  edits preset save FILE.json|- [--if REV]   save a changed preset (your folder wins over the built-in one)
  edits preset set NAME KEY=VALUE... [--as NEW] [--if REV]   change a preset without a script: total=12 shots.0.zoom=1.3
                               shots.*.speed=2 (lists count from 0, * is every shot); --if refuses it when the
                               preset changed since `preset show` gave that revision
  edits preset undo NAME       take the last change back (again: one more step back, finally the built-in one)
  edits preset import <zip|xml|dir|prfpset>...   Alight Motion projects, CapCut drafts and Premiere presets into presets
  edits library add <zip|folder>...       a whole editing pack: sounds, music, overlays, transitions, green screens,
                               memes, images into your library, fonts installed, presets imported
  edits library [KIND] [WORDS] what is in it (sfx, music, overlay, transition, greenscreen, background, meme, image)
  edits looks                  the colour looks
  edits learn <edit.mp4|link>...  reverse-engineer an edit you like (file, or an X/TikTok/Instagram/YouTube link) into a preset (cuts, flashes, zoom, slide, shake)
  edits draw <video> SPEC...   draw arrows, rings, crosses or your own .svg over a finished clip (see --svg)
                               and --overlay SPEC library clips (see --overlay)
  edits check <clip.mp4|link> measure a render: length, loudness, cut rhythm, a contact sheet to look at
  edits words <link|ID|file> [A-B] [--find TEXT]   what it says, line by line, each as a ready --say ID@A-B
  edits frames <video|ID> AT[+LEN]...   rows of frames at those seconds (336, 5:36, 336+4) in one jpg, to pick --shot
  edits song <video|link|ID> [AT]   which song plays there (Shazam), ready for --music
  edits cut <video|link|ID> A-B...  stretches copied out without re-encoding (lossless, instant), each from the keyframe before A
  edits font NAME...          a Google Fonts family for caption styles ("Bebas Neue", "Montserrat Black");
                               a style naming one this machine lacks fetches it by itself
  edits cube LOOK [out.cube]   an imported colour pack look as a .cube LUT for Premiere, Resolve, CapCut
  edits mcp                    serve every command to an AI agent (MCP over stdio)
  edits mcp install            add it to every agent here: Claude Code, Codex, OpenCode, Cursor, Windsurf,
                               Gemini CLI, Claude Desktop, VS Code
  edits guard install [--ask]  only if you want it: Claude Code refuses ffmpeg, yt-dlp and whisper run by hand
                               (--ask: asks you each time instead); edits guard remove takes it out again
  edits skills [install]       agent skills for every command
  edits skills catalog | add PACK [SKILL...]   skill packs from other projects (Remotion, YouTube research), fetched from GitHub
  edits trends [spotify] [country]   what is trending on TikTok now (default tr), or Spotify's daily chart; use with --music trend:N / spotify:N
  edits study <folder>         measure edits you like; their shape, grade and loudness become the defaults
  edits stats <@channel|link> [N]   the last N posts (default 30) with views, likes, comments; which are edits made
                               here (matched by their sound) and which presets, songs and looks did best; talking
                               clips that did best and worst become liked/disliked examples in your taste file
  edits review <clip.mp4> [--notes]   the clip in your browser: click a moment, a shot or a spot in the frame and
                               say what to change; the notes come back (and are saved as clip.notes.json)

OPTIONS
      --music SONG    make music edits: the footage's best shots cut on the song's beats (link, file, a library song, or
                      trend:N for TikTok's Nth trending song, trend:us:N for another country, spotify:N for Spotify's daily chart)
      --preset NAME   replay a preset (name or .json file) over the footage: timing, speed, moves, shakes, flashes, song
      --intensity K   preset moves: 0.5 calmer, 2 wilder (default: the preset's own)
      --like EDIT     copy a reference edit (file or link): its music (dialogue removed), cuts, flashes, colour and shape
      --sad           slow cuts, slow motion, crossfades, black and white
      --corecore      many unrelated videos of a topic, faded and grainy, dips to black, glimpses, headlines from
                      their own words over a slow song (needs --music)
      --loop          the end runs into the start, picture and song, no fades: it plays round seamlessly
      --long          one edit over a minute (TikTok's Creator Rewards pays only for those): talking clips are joined
                      into long.mp4, music edits run 64 s, a preset plays round on one song
      --lyrics        the song's words on screen as they are sung (the record's own lyrics from LRCLIB when it has
                      them, else what whisper hears); music edits cut on the sung words
      --voice         the speaker's best whole passage over their own footage, music under it, the drop as it ends, captions
      --shot ID@S[:X] preset edits: the footage for each shot by hand, in order (repeat), X = where the frame looks (0..1)
      --say ID@A-B    use what that video says from A to B seconds (repeat for more edits), whole words; also over --preset edits; implies --voice
                      ID@A-B+G+C-D (preset edits): those stretches joined into one line, G s of silence between
      --length S      seconds per music edit (default 18, sad 24)
      --tag TEXT      small signature at the bottom, like @yourname
      --text TEXT     a line over the whole music edit, in heavy capitals ("THE PROBLEM")
  -n, --moments N     clips (or music edits) to make, the best across all videos (default 3)
      --videos N      videos to look at for a topic or channel (default 5)
      --use K         music/preset edits: of those, read every one's captions and download only the best K (default 4)
      --aspect A      9:16 (default), 4:5, 1:1, 3:4, 4:3, 16:9 or 21:9
      --size WxH      any frame size, like 1080x1350
      --fit           keep the whole frame over a blurred copy instead of cropping around faces
      --look L        colour: none, bw, noir, dark, teal, tealorange, warm, cold, faded, vintage, sepia, bleach,
                      neon, matrix, sunset, pop
      --lut FILE      a .cube LUT over the picture
      --encoder E     auto (default: Apple VideoToolbox on a Mac, an NVIDIA GPU elsewhere, when it works, else libx264),
                      nvenc, videotoolbox or cpu; edits encoder E (or EDITS_ENCODER) sets it for every run
      --lang L        spoken language (default: $EDITS_LANG, else the system's); its words are in presets/lang.json
  -o, --out DIR       output folder (default: a new folder per run in $EDITS_OUT or ~/Videos/edits, by day and title)
      --join          also join all clips into joined.mp4
      --preview       one edit at half size, encoded fast: check timing and shots, then render without it
      --captions S    talking clips' caption style: hormozi (default), mrbeast, karaoke, box, minimal, neon
      --bed SONG      music under talking clips, ducked under the voice (link, file or trend:N)
      --caption TEXT@FROM-TO  words on screen at the top (repeat), emoji in colour: "sayın barış özbay 🗿@0-3.5"
      --say-text      draw the --say line as it is said, in the --captions style
      --math          formulas and waves flash in for a split second on the cuts
      --formula TEX   your own formula in the math layer, LaTeX: '\int_0^\infty e^{-x^2}dx' (repeat; implies --math)
      --flash-text SECONDS:TEXT  a subliminal line, two frames on black in the --captions style (repeat)
      --intro VIDEOID@FROM-TO[/PIC]  a short piece before the edit (its words, its picture from PIC), or a file
      --intro-bed SONG   a song under the intro, quiet, stopped by a record scratch
      --intro-caption TEXT  words over the intro
      --outro edits|FILE  the EditsMaker card (or a clip) after the edit
      --speed K       footage speed (talking clips: speech speed), 0.5 slow motion, 2 double
      --velocity      speed ramps on every longer shot: slow, rushing, slow onto the beat
      --fx LIST       hits on the hardest beats: shake, flash, rgb, glitch, invert, blur, freeze, zoom, strobe, bw, pulse
      --lines N       N sentences from the videos' own words on screen (music and preset edits)
      --line TEXT     a line of your own on screen (repeat for more); replaces the picked ones
      --blur-faces    blur faces   --blur-box x,y,w,h  blur a region (fractions of the frame)
      --bg B          the person cut out, another background behind them: blur, a colour (black, #ff2a6d), or a
                      picture or video (a file or a library background); the model is fetched once (people)
      --behind TEXT[@FROM-TO]   huge words behind the person (repeat), at the height the person covers least
      --outline COLOUR   a glowing outline around the person (white, #00e5ff)
      --anim A        how --caption and --svg come in: rise (default), pop, slam, slide, drop, blur, type
      --fix           dark, flat or dull footage brought up before the look (levels stretched, colour back)
      --svg NAME[@FROM-TO][:X,Y,SIZE][#COLOUR][~ANIM]   draw an arrow, circle, underline, cross, check, burst,
                      question, exclaim, heart, sparkle or your own .svg over the edit (repeatable)
      --overlay NAME[@FROM[-TO]][:OPACITY]   a library clip (or file) over the edit: textures screened under all of
                      it, a transition or meme once at FROM, green screens keyed (repeatable)
      --whoosh NAME   --boom NAME   talking clips: library sounds for the cuts and the punchline
      --pip FILE[@FROM-TO][:X,Y,SIZE]  another video (or library clip) small in a white frame over the edit,
                      centre X,Y and width SIZE as fractions (default top right); --overlay takes :X,Y,SIZE too
      --transition T  music edits: this transition on every soft cut (fade, dissolve, wipeleft, slideup, circleopen,
                      pixelize, radial, squeezeh, coverleft, revealup, hblur and every other ffmpeg xfade)
      --curves C      a tone curve over the edit: vintage, strong_contrast, cross_process, darker, lighter, ...
                      or your own points "0/0 0.4/0.3 1/1"
      --pop COLOUR    colour pop: only red, yellow, green, cyan, blue or magenta stays, the rest goes grey
      --bass DB       low end boost (6 = phonk)   --pitch N  semitones up or down, tempo kept
      --reverb        a room behind the sound (slowed + reverb)
      --denoise       clean the voice: a --say line loses the noise and score under it (DeepFilterNet), talking clips their hiss
      --stabilize  --smooth  --fps N  --codec h264|h265|prores|av1  --quality draft|high|master
      --export LIST   timelines beside each clip for other editors: fcpxml, edl, srt, vtt; fcpxml and edl carry
                      markers on every beat, the drop and where the voice comes in
      --no-jumpcuts   keep the pauses   --no-sfx  no whoosh/boom   --no-hook  no title on top
      --no-captions   no burned-in captions
      --no-llm        pick moments from viewer signals only

ENVIRONMENT
  EDITS_LLM            command that reads a prompt on stdin (default: claude -p)
  EDITS_WHISPER_MODEL  path to a ggml whisper model

Your taste lives in ~/.config/edits/taste.md. Edit it freely.
